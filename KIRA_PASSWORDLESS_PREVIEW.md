# KIRA password-free real EdgeOne review test
On non-casto.top EdgeOne preview URLs, /review.html and /reports.html request the
actual EdgeOne Blob queue and handle real batches, media checks, report decisions
and revisioned writes. No login or password field. Changes persist in
catalog/v2/review-test/v1/ shadow namespace of the REAL Blob store.
They do NOT alter production visibility, gallery content, or user reports.
On kira.casto.top, normal administrator authentication remains active.
This mode does not unlock manual upstream collection or global tag changes.
